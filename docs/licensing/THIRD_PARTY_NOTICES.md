# Third-party software and notices

**Status:** dependency audit completed for build 0.9.2 (2026-11-12). Re-run it when `go.mod` changes.

ReelAnvil distributes only its own application, our scripts and configuration, and its documentation. The installer's Compose file references third-party container images that the user's host pulls directly from their upstream registries. Third-party model weights, services and executables are **not** bundled, mirrored or repackaged by ReelAnvil. Referencing that software does not make it part of ReelAnvil's MIT license; each project keeps its own license.

## Compiled into the ReelAnvil binary

The Go modules below are linked into the release binary (listed with `go list -deps ./cmd/reelanvil`). SQLite itself is embedded through the pure-Go transpilation in modernc.org/sqlite, which carries the SQLite public-domain dedication and the modernc BSD-3-Clause license. The web UI has no third-party scripts or fonts, and its icons and artwork are ReelAnvil's own. Captions burned into clips use fonts already installed on the user's host; none are bundled. Each module's license text is reproduced in full at the end of this file, as the BSD and MIT terms require for binary distribution.

## Used at run time, not distributed by ReelAnvil

These are pulled or installed from their upstream sources on the user's host. Licenses are as the projects publish them; check the version you install.

| Component | How it arrives | Upstream license (as published) |
| --- | --- | --- |
| Ollama | Container `docker.io/ollama/ollama`, pinned by digest in the installer's Compose file | MIT |
| faster-whisper through the Wyoming protocol | Container `docker.io/linuxserver/faster-whisper`, pinned by digest | faster-whisper MIT; the linuxserver image packaging is GPL-3.0 |
| FFmpeg | Inside the container `docker.io/nandyalu/python-ffmpeg` (tracks `:latest` so yt-dlp stays current) | LGPL-2.1+ or GPL-2+, depending on the build |
| yt-dlp | Inside the same media container | Unlicense (public domain) |
| AI models (for example Qwen 2.5 through Ollama, Whisper models) | The user pulls them from the model provider | Model-specific terms; the user accepts them when pulling |

ReelAnvil talks to these only over their own network or command-line interfaces. Using ReelAnvil with other versions or other services is the user's choice and responsibility. The user is responsible for having the rights to every video they import.
