Storage locations

Settings, the database and logs. Set with reelanvil serve --data-dir; it cannot be changed here.

An absolute folder path using letters, digits and . _ - /. {{if .Default}}No path is saved yet, so ReelAnvil uses a media folder beside its data directory.{{else}}Saving creates the sub-folders below if the root exists. Nothing is ever deleted or moved.{{end}}

The most space ReelAnvil may use under the media root; 0 means no limit. 1 GB is 1,073,741,824 bytes. When the limit is reached, new jobs are blocked; nothing is deleted.

Check tests the path as typed, without saving it: the folder exists, a test file can be written and removed, free space, and space used under the root compared with the limit.
